- **More than one save:** the game kept one save on a Controller Pak and asked to overwrite it at every later save; on a console another save needed another pak. Save Game now makes a new note each time, up to 16 saves (15 beside a multiplayer note) on a pak twelve times the size of a console's, and asks to overwrite one only once the pak is full. Each save loads from the load screen's list, and a save from an earlier version carries over.
- **Graphics:** the newest RT64 fixes from the web support, among them a camera cut no longer drawing rectangles and HUD text halfway between the two shots in the frames between.
