An update to Turok 2: Recompiled, for Windows and Linux: turning and looking answer the stick and keys sooner.

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**What's new:**

- **Less input lag:** the picture used to show each of the game's frames one frame after the game had made it. Now it shows each as soon as it is drawn, so a turn or a look reaches the screen about 25 ms sooner at the game's 30 frames a second (from the game turning the view to the picture: 150 ms instead of 170 ms, median). The rest of the delay is the game's own: it reads the stick and moves its camera a couple of frames ahead of the frame it shows, as it does on a console.

**Windows:** unzip `Turok2Recompiled-v0.2.14-windows-x64.zip` and run `Turok2Recompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `Turok2Recompiled-v0.2.14-linux-x64.tar.gz` and run `Turok2Recompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2). You need your own ROM of the USA release, revision 1.0 (a big-endian `.z64` of 32 MiB, SHA-1 `fb0400f21e3f043939ab56500c7b12a3231006f1`): pick it with **Load ROM**, then **Start Game**.

**Not checked yet:** the change on Windows (it was measured on the Linux build), a whole playthrough (reports are welcome on the [issues page](https://github.com/n64hub/turok-2-recomp/issues)), long play sessions, and the Linux build on a GPU (it has been booted on Mesa's software Vulkan only).

The same game plays in a browser at [n64hub.com/turok-2](https://n64hub.com/turok-2/), with the same change.
