An update to Turok 2: Recompiled, for Windows and Linux: with the map open and Frame Interpolation on, the map and the level are drawn as one frame.

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**What's new:**

- With the map open (Tab) and Frame Interpolation on, the frames it adds between the game's own are drawn from the level and the map together, as the browser version draws them, rather than each on its own.

**Windows:** unzip `Turok2Recompiled-v0.2.4-windows-x64.zip` and run `Turok2Recompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `Turok2Recompiled-v0.2.4-linux-x64.tar.gz` and run `Turok2Recompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2). You need your own ROM of the USA release, revision 1.0 (a big-endian `.z64` of 32 MiB, SHA-1 `fb0400f21e3f043939ab56500c7b12a3231006f1`): pick it with **Load ROM**, then **Start Game**.

**Known:** with Frame Interpolation at a rate above the game's own, the map still drops out of a few of the frames it adds while you move; at Original it never does.

**Not checked yet:** the levels after the first and a whole playthrough (reports are welcome on the [issues page](https://github.com/n64hub/turok-2-recomp/issues)), long play sessions, and the Linux build on a GPU (it has been booted on Mesa's software Vulkan only).

The same game plays in a browser at [n64hub.com/turok-2](https://n64hub.com/turok-2/).
