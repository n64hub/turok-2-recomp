An update to Turok 2: Recompiled, for Windows and Linux: nothing of the level goes missing with the Fog off, and Start works in a save portal's menus.

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**What's new:**

- **Draw Distance** (Graphics): Far, the new default, draws all of the level the game has loaded. The console leaves out whole buildings and walls its fog would hide, and with Fog off they showed as sky, coming and going as the camera moved. Normal draws what the console does. Fog Off still draws the world four times as far, at either.
- **Nothing near you goes missing in busy views:** the game keeps a short list each frame of what it is about to draw, and where the list filled up (in the Port of Adia's towns, most of all at Far) it left out what came last, the ground and walls nearest the camera. The list now has eight times the room.
- **Start works in a save portal's menus:** the recomp's cinematic skip took Start from the game while the portal's shots played, so only A (RB on a pad, E on the keyboard) chose anything there. Start is the game's in a save portal now, as on the console.

**Windows:** unzip `Turok2Recompiled-v0.2.19-windows-x64.zip` and run `Turok2Recompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `Turok2Recompiled-v0.2.19-linux-x64.tar.gz` and run `Turok2Recompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2). You need your own ROM of the USA release, revision 1.0 (a big-endian `.z64` of 32 MiB, SHA-1 `fb0400f21e3f043939ab56500c7b12a3231006f1`): pick it with **Load ROM**, then **Start Game**.

**Not checked yet:** the changes on Windows (they were checked on the Linux build, in the Port of Adia and at its first save portal), the rest of the game's levels at Far, a whole playthrough (reports are welcome on the [issues page](https://github.com/n64hub/turok-2-recomp/issues)), and the Linux build on a GPU (it has been booted on Mesa's software Vulkan only).

The same game plays in a browser at [n64hub.com/turok-2](https://n64hub.com/turok-2/).
