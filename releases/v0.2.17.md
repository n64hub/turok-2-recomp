An update to Turok 2: Recompiled, for Windows and Linux: the cutscenes show as they did before v0.2.16.

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**What's new:**

- **Cutscenes as before v0.2.16:** the cutscenes, which run at 15 frames a second, are shown as they were in v0.2.15 again: v0.2.16 showed each of their frames as soon as it was drawn, which made them judder, and in the Port of Adia's opening cutscene a limb close to the camera could flash for a frame. That now happens only while you play, at 30 frames a second, so the lower input lag of v0.2.16 stays: about 96 ms from a press of the stick or a key to the picture, measured as for v0.2.16.

**Windows:** unzip `Turok2Recompiled-v0.2.17-windows-x64.zip` and run `Turok2Recompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `Turok2Recompiled-v0.2.17-linux-x64.tar.gz` and run `Turok2Recompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2). You need your own ROM of the USA release, revision 1.0 (a big-endian `.z64` of 32 MiB, SHA-1 `fb0400f21e3f043939ab56500c7b12a3231006f1`): pick it with **Load ROM**, then **Start Game**.

**Known:** where the camera cuts through a figure in the Port of Adia's opening cutscene, a dark frame can show for a moment, as in v0.2.15.

**Not checked yet:** the change on Windows (it was checked on the Linux build), a whole playthrough (reports are welcome on the [issues page](https://github.com/n64hub/turok-2-recomp/issues)), long play sessions, and the Linux build on a GPU (it has been booted on Mesa's software Vulkan only).

The same game plays in a browser at [n64hub.com/turok-2](https://n64hub.com/turok-2/), with the same change.
