An update to Turok 2: Recompiled, for Windows and Linux: the game reaches its title sooner.

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**What's new:**

- **Skip Intro is quicker:** the "Accessing the Controller Pak" screen no longer waits about 4 seconds after reading the pak, and the legal screen goes as soon as it comes, so the title is up about 4 s after the game starts instead of 13. With Skip Intro on, holding Start as the game starts no longer opens the Controller Pak's menu; turn Skip Intro off (General) to reach it, as on the console.

**Windows:** unzip `Turok2Recompiled-v0.2.15-windows-x64.zip` and run `Turok2Recompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `Turok2Recompiled-v0.2.15-linux-x64.tar.gz` and run `Turok2Recompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2). You need your own ROM of the USA release, revision 1.0 (a big-endian `.z64` of 32 MiB, SHA-1 `fb0400f21e3f043939ab56500c7b12a3231006f1`): pick it with **Load ROM**, then **Start Game**.

**Not checked yet:** the change on Windows (it was played on the Linux build), a whole playthrough (reports are welcome on the [issues page](https://github.com/n64hub/turok-2-recomp/issues)), long play sessions, and the Linux build on a GPU (it has been booted on Mesa's software Vulkan only).

The same game plays in a browser at [n64hub.com/turok-2](https://n64hub.com/turok-2/), with the same change.
