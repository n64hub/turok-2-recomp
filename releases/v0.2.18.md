An update to Turok 2: Recompiled, for Windows and Linux: the map no longer stutters.

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**What's new:**

- **The map no longer stutters:** with the map open, v0.2.16 and v0.2.17 showed each of the game's frames twice, the first time without the map, so on a display faster than 60 Hz the map flickered and the picture stuttered. A frame with the map is shown once again, as in v0.2.15. While the map is open, a press takes one retrace (17 ms) longer to reach the picture than with it closed.

**Windows:** unzip `Turok2Recompiled-v0.2.18-windows-x64.zip` and run `Turok2Recompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `Turok2Recompiled-v0.2.18-linux-x64.tar.gz` and run `Turok2Recompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2). You need your own ROM of the USA release, revision 1.0 (a big-endian `.z64` of 32 MiB, SHA-1 `fb0400f21e3f043939ab56500c7b12a3231006f1`): pick it with **Load ROM**, then **Start Game**.

**Not checked yet:** the change on Windows (it was checked on the Linux build, at 60 and 120 Hz), a whole playthrough (reports are welcome on the [issues page](https://github.com/n64hub/turok-2-recomp/issues)), long play sessions, and the Linux build on a GPU (it has been booted on Mesa's software Vulkan only).

The same game plays in a browser at [n64hub.com/turok-2](https://n64hub.com/turok-2/).
