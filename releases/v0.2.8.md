An update to Turok 2: Recompiled, for Windows and Linux: with a gamepad, looking up and down with the stick moves the view at once and the view stays where you leave it.

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Fixed:**

- With a gamepad, looking up and down with the right stick (and the arrow keys) now moves the view at once, at a speed set by how far the stick is pushed, and the view stays where you leave it. Before, the view eased slowly towards the stick's angle, about a second behind it, and sprang back level as soon as the stick was let go, so an aim up or down couldn't be held.

**Windows:** unzip `Turok2Recompiled-v0.2.8-windows-x64.zip` and run `Turok2Recompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `Turok2Recompiled-v0.2.8-linux-x64.tar.gz` and run `Turok2Recompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2). You need your own ROM of the USA release, revision 1.0 (a big-endian `.z64` of 32 MiB, SHA-1 `fb0400f21e3f043939ab56500c7b12a3231006f1`): pick it with **Load ROM**, then **Start Game**.

**Not checked yet:** the levels after the first and a whole playthrough (reports are welcome on the [issues page](https://github.com/n64hub/turok-2-recomp/issues)), long play sessions, and the Linux build on a GPU (it has been booted on Mesa's software Vulkan only).

The same game plays in a browser at [n64hub.com/turok-2](https://n64hub.com/turok-2/).
