An update to Turok 2: Recompiled, for Windows and Linux: the game no longer crashes when the graphics take a long time with a frame.

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**What's new:**

- **No crash on a slow frame:** the game had a check of its own that stopped it when a frame went 20 seconds without being drawn, which on a console meant the graphics chip had hung. On a PC a frame can take that long on a slow or software graphics driver (Mesa's lavapipe on a busy machine did, early in the game), and the game then closed without a word. The check is gone, so a slow frame is just slow.

**Windows:** unzip `Turok2Recompiled-v0.2.24-windows-x64.zip` and run `Turok2Recompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `Turok2Recompiled-v0.2.24-linux-x64.tar.gz` and run `Turok2Recompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2). You need your own ROM of the USA release, revision 1.0 (a big-endian `.z64` of 32 MiB, SHA-1 `fb0400f21e3f043939ab56500c7b12a3231006f1`): pick it with **Load ROM**, then **Start Game**.

**Not checked yet:** a whole playthrough (reports are welcome on the [issues page](https://github.com/n64hub/turok-2-recomp/issues)), and the Linux build on a GPU other than NVIDIA's.

The same game plays in a browser at [n64hub.com/turok-2](https://n64hub.com/turok-2/).
