An update to Turok 2: Recompiled, for Windows and Linux.

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**What's new:**

- Mouse look is on from the first start (General, Mouse Sensitivity, 50%; 0 turns it off and leaves the cursor free). If you played v0.1.0 or v0.1.1, your saved settings have it at 0, so turn it up there
- Up looks up: moving the mouse up, the up arrow and the right stick pushed up now look up; in v0.1.x they looked down, since the game looks down with its stick pushed up, as a plane's stick does
- In widescreen, opening the map (Tab) no longer draws a thin line down the picture at each of the old 4:3 edges

**Windows:** unzip `Turok2Recompiled-v0.2.0-windows-x64.zip` and run `Turok2Recompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `Turok2Recompiled-v0.2.0-linux-x64.tar.gz` and run `Turok2Recompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2). You need your own ROM of the USA release, revision 1.0 (a big-endian `.z64` of 32 MiB, SHA-1 `fb0400f21e3f043939ab56500c7b12a3231006f1`): pick it with **Load ROM**, then **Start Game**.

**Not checked yet:** the levels after the first and a whole playthrough (reports are welcome on the [issues page](https://github.com/n64hub/turok-2-recomp/issues)), long play sessions, and the Linux build on a GPU (it has been booted on Mesa's software Vulkan only).

The same game plays in a browser at [n64hub.com/turok-2](https://n64hub.com/turok-2/).
